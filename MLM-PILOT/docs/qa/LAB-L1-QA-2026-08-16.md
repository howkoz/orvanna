## Defects

**HIGH-1 (blocks the phase): the calibrated-rate spec amendment is missing.**
Spec section 7 lists L1 deliverables as "...the calibration run and the
calibrated rate amendment", and Howard's section 8 ruling 3 says the spec "is
amended with the number the same day". The run exists and its numbers are
verified (candidate rates 0.105 for bfs_spill, 0.110 for volume_balanced);
the amendment does not, and the calibration rule's ambiguity (which strategy
anchors) is unresolved. Owner: mlm-architect, who must also settle the
builder's related flags (spec 6.3 mini-tree spread parenthetical, the
extra-root ruling, the fifth defaulted parameter). Re-gate scope after the
amendment: rows A18 and F1 only.

**MEDIUM-1: completed lab run rows are structurally editable.** The registry
trigger on lab.plan_runs fires on INSERT and DELETE only; scenarios and
mutations are trigger-frozen, but a completed run's plan_params, totals, or
notes could be UPDATEd by the service role, against the spec's "a rerun ...
is a NEW run, never an edit" discipline (sections 1.1 and 4). Exposure is
service-role-only and the generated disclaimer and caption columns cannot be
blanked, so this is fragility, not breakage. Suggested for L2: extend the
discipline trigger to freeze rows once status is 'complete', mirroring the
scenario freeze.

**LOW-1: ROADMAP lab status is stale.** "Spec in flight" understates a built,
cloud-applied L1 awaiting gates. Update when the phase closes (or now, to
"L1 built, both gates pending").
