ORVANNA sandbox test cards

For the live demo checkout at orvanna.io and the HyperSwitch sandbox dashboard. These are industry-standard test numbers: they work ONLY in sandboxes, move no real money anywhere, and are public knowledge (safe to share, print, or store openly).

Expiry and security code: any FUTURE expiry date (for example 12 / 30) and any 3 digit Card Verification Value (CVV), for example 123. American Express uses a 4 digit code. Cardholder name can be anything.
