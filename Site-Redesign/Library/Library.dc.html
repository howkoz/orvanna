SAY THIS, NOT THE OTHER THING

All three packs cost exactly what their contents cost. There is no saving, and a Conductor who implies one will be caught by the first customer who adds it up. What a pack buys is curation — somebody already decided which agents belong together at this stage.

The Manager Agent runs the other way, and the difference is the product. Selling it as a discount would be both false and weaker than the truth.

WHY INCLUDED AGENTS SHOW AT $0.00

The parent line already carries the full price and the full Personal Volume for the whole group. Money is never charged twice and volume is never counted twice — a pack's PV is the whole volume for that purchase, not the pack plus everything inside it.

HONEST ABOUT LIMITS

Every agent has an approval boundary, and this library states it

An agent that prepares a tax return does not file it. An agent that drafts a refund does not issue it. Saying so builds more trust than hiding it — and it is the second question a customer asks, so you will need the answer either way.

Every agent page answers the same six questions in the same order, so once you can read one you can read all sixteen.
