# Orvanna brand folder

As of 2026-08-13. Five first-round logo concepts for Orvanna (the domain is
orvanna.io; first product wearing the name is the MLM Pilot's agent marketplace demo).

Palette: indigo #4F46E5 (primary), cyan #22D3EE (accent, "the lit node"), ink #0F172A
(wordmark). Flat colors only, no gradients, white background versions here; dark
variants get made once a direction is picked.

| File | Concept | The idea |
|---|---|---|
| logo-1-network-ring.svg | Network Ring | members connected in a ring form the O; the lit node is YOU |
| logo-2-orbit.svg | Orbit | the O is an orbit with one agent riding it; calm, minimal |
| logo-3-wordmark-circuit.svg | Circuit Underline | pure wordmark; the underline steps UP like an upline to a lit node |
| logo-4-hex-team.svg | Hex Team | badge: a hub agent coordinating a team inside a hexagon; works as app icon alone |
| logo-5-ascent.svg | Ascent | three rank chevrons climbing; the summit chevron is lit |

Pick one direction and the next pass produces: dark-background variant, square app
icon / favicon crop, and size tests (16 px favicon up to hero banner).
